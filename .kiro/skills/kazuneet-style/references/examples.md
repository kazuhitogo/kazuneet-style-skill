# 文体の実例 (元記事からの短い抜粋)

文体の参照用。文章をそのまま流用せず、リズムと型を真似る。

## 冒頭の型

- 一次情報 + 一言: 「出ました。」(AgentCore GA 記事)
- 今北産業: 「今北産業すると、/ Quotas に引っ掛かってスロットリングしても / 空いているリージョンで推論できる仕組みが / できたよ」(Cross Region Inference)
- 悩みから入る: 「ミスった Agent 起動、どうやって止めるのよ、という話」「そんなとき動いている Agent を止められるのか、というお話」
- 宣言: 「この記事では裏側の動作とかについては一切触れずに、どうやって動かすのか、にフォーカスして記載していきます。」
- 受け身の導入: 「さておき、Amazon Bedrock で Cohere の Command R と Command R+ が来ましたね。」
- 公式情報の速報: 「いつの間にかアップデートが走ってました。」

## 括弧の独り言

- 「(結局 ModelId 引数を使うのね)」
- 「（確認したつもり何だがなぁ）」
- 「東京リージョンでもできるのがとてもうれしかったですね（小並感」
- 「CDK が使えること(早くもチートのかほり）」
- 「当然クレデンシャル、ポリシー、などはちゃんと設定されてるよね？」
- 「（私がハマった）」

## ぼかしと正直さ

- 「たぶん。」「(しらんけど)」「（はず）」
- 「Agent のレジュームの仕方に確信をもっていないのでなんともですが、〜っぽいです」
- 「いまいち再現もしないし怪しいです。」
- 「2025/8/12 の情報なのでアップデートが走ってもしりません。」
- 「やはり日本語はダメでした。」
- 「(2022/2/16 追記: やりませんでした)」

## ネタの作り方

- 漫画・アニメの台詞のもじりをタイトルや見出しに使う (「〜ッ！よくもクオータをッ！」「気分はディリータです」)。本文の技術は真面目に書く。
- 野球選手や有名な速さの例えを、技術的な「速さ・無駄遣い」の比喩にする。
- 独自の造語は「これは私が勝手に命名したものですが」と断る (MCP = Minecraft Play)。
- ゲームや家庭の話を、技術を試す動機に使う。
- 危ない題材には冒頭で `:::note warn` を置く。

## 締めの型

- 「以上、雑検証でした。」
- 「以上、とりあえずやってみたでした。」
- 「以上、SageMaker Studio 大好きな人からの記事でした。」
- 「ちゃんちゃん。」
- 「では〜」
- 「というわけで SageMaker の新しい仲間、shadow test をよろしくおねがいします！」
- 「ぜひこの使い方を覚えましょう。」
- 「まずは使ってみてはいかがでしょうか。」

## 結論を言い切る場面

実測の数値があるときは、言い切ってよい。数値と、その解釈を 1 文ずつで書く。

- 「だいたい 6 分かかりましたね。インスタンス起動、コンテナイメージとモデルの DL およびロードなのでそんなもんか、という数値でした。」
- 「書き出しを見る限り latency optimize も標準と変わっていません。精度を維持したまま高速化したい、という要望にはお金で解決する、というオプションが加わったと考えることができます。」
